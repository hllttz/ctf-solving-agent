# Solver Skills

Drop optional `.md` skill files in this directory to add challenge-specific guidance to the solver prompt.

Keep each skill concise and action-oriented. A skill should describe what to try first and which tools or commands are useful.

The solver injects only:

- `common.md` for every challenge.
- `{category}.md` for the challenge category, such as `rev.md`, `crypto.md`, `web.md`, `pwn.md`, `forensics.md`, or `misc.md`.
